0 でない数どうしのかけ算・わり算では、絶対値どうしを計算し、同じ符号なら正、異なる符号なら負の符号をつけます。どちらかが 0 のかけ算と、0 を 0 でない数でわる計算の答えは 0 です。0 でわることはできません。
