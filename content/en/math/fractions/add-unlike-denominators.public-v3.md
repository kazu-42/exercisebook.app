# Add fractions with unlike denominators

To add fractions with different denominators, first rewrite both fractions with
the same denominator. Then add the numerators and reduce the result.

:::worked-example{id="worked-example-01" title="One half plus one third"}
The least common denominator of $2$ and $3$ is $6$. Rewrite $\frac{1}{2}$ as
$\frac{3}{6}$ and $\frac{1}{3}$ as $\frac{2}{6}$. Then add:
$\frac{3}{6} + \frac{2}{6} = \frac{5}{6}$.
:::
